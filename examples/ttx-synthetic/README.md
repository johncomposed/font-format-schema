# Synthetic TTX fixtures

These tiny fonts are generated by `scripts/build-synthetic-fonts.py` using the pinned fontTools version. They are intentionally minimal so the XML remains readable.

- `avar2-demo.ttx` — two `fvar` axes plus `avar` version 2, `VarIdxMap` and `VarStore` generated from a multi-axis mapping.
- `hvar-demo.ttx` — one-axis `HVAR` with a `VarStore` and explicit `AdvWidthMap` entries.
- `varc-demo.ttx` — one-axis `VARC` with `AxisIndicesList`, a `VarCompositeGlyph`, component-local `axisValues`, and a translated component.

The `.ttf` files are the exact compiled inputs used to produce the checked-in TTX examples. Each `*.full.ttx` contains the complete font and can be compiled back to a font; the shorter `.ttx` file is the variation-table-focused view.
