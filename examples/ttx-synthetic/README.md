# Synthetic TTX fixtures

These tiny fonts are generated by `scripts/build-synthetic-fonts.py` with the pinned fontTools version. They are intentionally minimal so the XML stays readable. Each has a compiled `.ttf`, a focused `.ttx` with only the interesting tables, and a `*.full.ttx` that round-trips to a font. `generated/ttx/json/<stem>.json` is each full dump converted to the `schemas/ttx.schema.json` model.

- `vf-demo` — a real `varLib.build` of six in-memory masters over `wght` (with a non-linear user→design map) and `wdth`: `fvar` with a named instance, `avar` version 1, `gvar` with an intermediate master (tuples carrying `min`/`max`), off-curve point deltas and a composite glyph with a varying component offset, `cvar` over two control values, `HVAR`, `STAT`, `glyf`/`hmtx`/`cmap`/`name`/`post`.
- `avar2-demo` — two `fvar` axes plus `avar` version 2, `VarIdxMap` and `VarStore` generated from a multi-axis mapping.
- `hvar-demo` — one-axis `HVAR` with a `VarStore` and explicit `AdvWidthMap` entries.
- `varc-demo` — one-axis `VARC` with `AxisIndicesList`, a `VarCompositeGlyph`, component-local `axisValues`, and a translated component.
